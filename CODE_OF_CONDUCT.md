# Contributor Covenant — Short Form

We want ShareCircle contributions to be welcoming, constructive, and safe.

Participants are expected to use respectful language, assume good intent while discussing technical work, accept actionable feedback, and focus criticism on ideas or code rather than people. Harassment, discrimination, threats, doxxing, and deliberately disruptive behavior are not acceptable.

Project maintainers may remove comments, close issues, or decline contributions that violate these standards. Serious concerns can be reported privately to the project maintainers.
